How it works

Two ways to document

Choose fully automatic or stay in control — the output is the same editable, structured guide.

Agent Automatic

Give the agent a URL, a feature name, and a brief goal. It navigates the app autonomously, captures a screenshot at each step, and drafts the full documentation. No mouse clicks required.

Assisted Human-guided

You drive through the feature yourself, clicking a capture button at each meaningful moment. The AI writes the step descriptions from what it sees in your screenshots.

Features

Everything you need

Built for teams that ship fast and need documentation that keeps up.

Multi-provider AI

Use Claude, Gemini, or any OpenAI-compatible endpoint. Switch providers per run.

Secure credentials

Login credentials for your apps are stored in the OS keychain. The agent signs in automatically.

Local-first

All runs, screenshots, and documentation are stored on your machine. Nothing is uploaded.

Editable output

Every step is fully editable in the app before you export or share the finished guide.

Screenshot capture

Automatic screenshots at each step, saved locally and embedded in the documentation.

Cross-platform

Native desktop app for Windows, macOS, and Linux. No browser extension needed.
